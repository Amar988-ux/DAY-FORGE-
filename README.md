⚡ DAYFORGE — Daily Growth Dashboard

Build discipline. Build your future. 🚀

DAYFORGE is a modern, glassmorphism-inspired personal productivity dashboard designed to help you manage daily routines, track fitness, monitor job applications, manage personal finances, record reading progress, and build consistent habits.

Built using HTML5, CSS3, JavaScript, and the HTML Canvas API, DAYFORGE combines productivity tracking with a futuristic interface and a focus on personal growth.

✨ Features

- 🌅 Morning Routine — Track daily habits, exercise, running, and fitness goals.
- 📚 Study Tracker — Monitor study sessions, focus time, and learning progress.
- 💼 Job Application Tracker — Track applications, statuses, and progress toward a daily target of 50 applications.
- 💰 Money Manager — Record income, expenses, savings, and available balance.
- 📖 Reading Journal — Save book details, favourite quotes, daily lessons, and reading progress.
- 🎮 Recharge Mode — Track leisure activities and gaming time.
- 🌙 Nightly Review — Review achievements, incomplete tasks, and priorities for tomorrow.
- 📊 Progress Analytics — Visualize productivity and weekly progress using Canvas charts.
- ⏰ Reminders — Configure daily reminders and browser notifications where supported.
- 💾 Local Data Storage — Save your progress in your browser using LocalStorage.
- 📱 Responsive Interface — Designed for desktop and mobile devices.
- 🧊 Glassmorphism UI — Frosted-glass cards, gradient accents, blur effects, and subtle animations.

🛠️ Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript
- HTML Canvas API
- Browser LocalStorage
- Git and GitHub

🚀 Getting Started

1. Clone or download this repository.
2. Open "index.html" in a modern web browser.
3. Start tracking your routines, learning, finances, and daily progress.

No framework or backend is required.

🔒 Data and Privacy

DAYFORGE stores dashboard data locally in your browser. Information is not automatically synchronized between devices.

Use the built-in JSON export feature to back up your data regularly.

🎯 Project Goal

The goal of DAYFORGE is to bring everyday productivity into one simple dashboard and encourage consistency in fitness, education, career development, financial awareness, and personal growth.
